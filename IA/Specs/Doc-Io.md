SPEC — Central de Documentação do Projeto Olliverse
1. Objetivo
Implementar no projeto Olliverse uma Central de Documentação acessível por meio do menu principal da aplicação.
A documentação deverá apresentar, de maneira organizada, todas as funcionalidades existentes no sistema, permitindo que usuários, desenvolvedores, analistas e responsáveis pelo projeto entendam:
o objetivo de cada módulo;
quais funcionalidades estão disponíveis;
como utilizar cada funcionalidade;
